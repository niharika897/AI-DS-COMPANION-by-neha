PYTHON BASICS

01. Python Basics 🐍

Let's understand the fundamentals of Python before moving on to advanced concepts.

1. What is Python?

Python is a high-level, general-purpose programming language known for its simple and readable syntax. It was created by Guido van Rossum and was first released in 1991.

Python is widely used in web development, data science, artificial intelligence, machine learning, automation, and software development.

2. Features of Python

  • Easy to learn: Python has a simple and readable syntax.
  • High-level language: Programmers do not need to manage low-level computer operations directly.
  • Interpreted: Python programs are executed by the Python interpreter.
  • Portable: Python programs can run on different operating systems with little or no modification.
  • Large library collection: Python provides many libraries for different programming tasks.
  • Object-oriented: Python supports object-oriented programming concepts such as classes and objects.

3. Where is Python Used?

🤖 Artificial Intelligence
📊 Data Science
🌐 Web Development
⚙️ Automation

4. Your First Python Program

The following program displays Hello, World! on the screen. 

print("Hello, World!")

Output: 

Hello, World!

5. Comments in Python

Comments are notes written inside a program to explain the code. They are ignored by Python when the program runs.

A single-line comment begins with the # symbol. 

# This is a comment
print("Hello")

📝 Quick Revision

  • Python was created by Guido van Rossum.
  • Python was first released in 1991.
  • Python is a high-level, general-purpose language.
  • Python has simple and readable syntax.
  • The print() function displays output.
  • The # symbol is used for comments.
PYTHON BASICS

02. Variables & Data Types 🧩

Variables are used to store data in a Python program. Python automatically determines the type of value stored.

1. What is a Variable?

A variable is a name used to store a value in memory. In Python, you do not need to declare the data type separately. 

name = "Neha"
age = 19
marks = 85.5

2. Common Data Types

  • int — whole numbers such as 10 or 25
  • float — decimal numbers such as 10.5
  • str — text such as "Hello"
  • bool — True or False
  • list — ordered collection of values
  • tuple — ordered, immutable collection
  • set — collection of unique values
  • dict — collection of key-value pairs

3. Checking the Data Type

The type() function can be used to find the type of a value. 

age = 19

print(type(age))

Output:

<class 'int'>

📝 Quick Revision

  • A variable stores a value.
  • Python determines the type automatically.
  • int stores whole numbers.
  • float stores decimal numbers.
  • str stores text.
  • bool stores True or False.
PYTHON BASICS

03. Operators ➕

Operators are symbols used to perform operations on values and variables.

1. Arithmetic Operators

Arithmetic operators are used for mathematical calculations. 

a = 10
b = 3

print(a + b)
print(a - b)
print(a * b)
print(a / b)
print(a % b)

Common operators include +, -, *, /, %, //, and **.

2. Comparison Operators

Comparison operators compare two values and return either True or False.

  • == Equal to
  • != Not equal to
  • > Greater than
  • < Less than
  • >= Greater than or equal to
  • <= Less than or equal to

3. Logical Operators

  • and — both conditions must be True
  • or — at least one condition must be True
  • not — reverses the result
age = 20

print(age > 18 and age < 30)

📝 Quick Revision

  • Operators perform operations on values.
  • Arithmetic operators perform calculations.
  • Comparison operators return True or False.
  • Logical operators combine conditions.
CONTROL FLOW

04. Conditions & Loops 🔄

Conditions and loops allow a program to make decisions and repeat instructions.

1. if Statement

The if statement executes a block of code when a condition is True. 

age = 20

if age >= 18:
    print("Eligible")

2. if, elif and else

These statements can be used when a program needs to check multiple conditions. 

marks = 75

if marks >= 90:
    print("A")
elif marks >= 60:
    print("B")
else:
    print("C")

3. for Loop

A for loop is commonly used to repeat code for each item in a sequence. 

for i in range(5):
    print(i)

4. while Loop

A while loop repeats code while its condition remains True. 

count = 1

while count <= 5:
    print(count)
    count += 1

📝 Quick Revision

  • if is used for decision making.
  • elif checks another condition.
  • else executes when previous conditions are False.
  • for repeats over a sequence.
  • while repeats while a condition is True.
REUSABLE CODE

05. Functions ⚙️

Functions are reusable blocks of code designed to perform a particular task.

1. Creating a Function

A function is defined using the def keyword. 

def greet():
    print("Hello!")

greet()

2. Parameters

Parameters allow a function to receive information when it is called. 

def greet(name):
    print("Hello", name)

greet("Neha")

3. Return Value

The return statement sends a result back to the part of the program that called the function. 

def add(a, b):
    return a + b

result = add(10, 20)

print(result)

📝 Quick Revision

  • Functions help avoid repeating code.
  • def is used to define a function.
  • Parameters provide input to a function.
  • return sends a value back.
COLLECTIONS

06. Data Structures 📦

Python provides built-in data structures that help programmers store and organize collections of data.

1. List

A list is an ordered and mutable collection. 

fruits = ["apple", "banana", "mango"]

print(fruits[0])

2. Tuple

A tuple is an ordered collection that cannot be changed after it is created. 

coordinates = (10, 20)

print(coordinates)

3. Set

A set is an unordered collection of unique values. 

numbers = {1, 2, 3, 3}

print(numbers)

4. Dictionary

A dictionary stores data as key-value pairs. 

student = {
    "name": "Neha",
    "age": 19
}

print(student["name"])

📝 Quick Revision

  • Lists are ordered and mutable.
  • Tuples are ordered and immutable.
  • Sets contain unique values.
  • Dictionaries store key-value pairs.
OBJECT-ORIENTED PROGRAMMING

07. Object-Oriented Programming 🧠

Object-Oriented Programming, or OOP, is a programming approach based on objects and classes.

1. Class

A class is a blueprint used to create objects. 

class Student:
    pass

2. Object

An object is an instance of a class. 

class Student:
    pass

student1 = Student()

3. Inheritance

Inheritance allows one class to acquire properties and methods from another class. 

class Animal:
    def speak(self):
        print("Animal sound")

class Dog(Animal):
    pass

4. Polymorphism

Polymorphism allows the same method or operation to behave differently depending on the object.

📝 Quick Revision

  • A class is a blueprint.
  • An object is an instance of a class.
  • Inheritance allows code reuse between classes.
  • Polymorphism allows different behaviors through a common interface.
FILE OPERATIONS

08. File Handling 📁

File handling allows Python programs to store, read, and modify information in files.

1. Opening a File

The open() function is used to open a file. 

file = open("notes.txt", "r")

2. Reading a File

file = open("notes.txt", "r")

content = file.read()

print(content)

file.close()

3. Writing to a File

The "w" mode can be used to write data to a file. 

file = open("notes.txt", "w")

file.write("Python is easy to learn.")

file.close()

4. Using with

The with statement is commonly used because it automatically handles closing the file. 

with open("notes.txt", "r") as file:
    content = file.read()
    print(content)

📝 Quick Revision

  • open() opens a file.
  • "r" is used for reading.
  • "w" is used for writing.
  • close() closes a file.
  • with provides convenient file handling.
