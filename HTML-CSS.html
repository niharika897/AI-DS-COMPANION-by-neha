HTML & CSS NOTES

Learn HTML & CSS Step by Step 📚

Learn how webpages are structured with HTML and styled with CSS through simple explanations and examples.

01. HTML Basics 🌐

HTML stands for HyperText Markup Language. It is used to create the structure and content of a webpage.

HTML uses tags to tell the browser what each part of the webpage represents.

Basic HTML Structure

<!DOCTYPE html>
<html>

<head>
    <title>My Website</title>
</head>

<body>

    <h1>Hello World!</h1>
    <p>Welcome to my website.</p>

</body>

</html>

Common HTML Tags

  • <h1> — main heading
  • <p> — paragraph
  • <div> — container
  • <br> — line break
  • <strong> — important/bold text

⚡ Quick Revision

  • HTML creates the structure of a webpage.
  • HTML uses tags and elements.
  • The <head> contains information about the page.
  • The <body> contains visible webpage content.

02. Links, Images & Lists 🔗

HTML allows us to add links, images and lists to make webpages more useful and interactive.

Links

<a href="https://example.com">
    Visit Website
</a>

The href attribute specifies where the link should take the user.

Images

<img src="photo.jpg" alt="My Photo">

The src attribute specifies the image location, while alt describes the image.

Unordered List

<ul>

    <li>Python</li>
    <li>Java</li>
    <li>HTML</li>

</ul>

Ordered List

<ol>

    <li>Learn HTML</li>
    <li>Learn CSS</li>
    <li>Build a Website</li>

</ol>

⚡ Quick Revision

  • <a> creates links.
  • <img> displays images.
  • <ul> creates unordered lists.
  • <ol> creates ordered lists.
  • <li> represents a list item.

03. Forms & Tables 📝

HTML forms are used to collect information from users, while tables are used to display structured data.

HTML Form

<form>

    <label>Name:</label>

    <input type="text">

    <label>Email:</label>

    <input type="email">

    <button>Submit</button>

</form>

Common Input Types

  • text
  • email
  • password
  • number
  • date
  • checkbox
  • radio

HTML Table

<table>

    <tr>
        <th>Name</th>
        <th>Marks</th>
    </tr>

    <tr>
        <td>Anu</td>
        <td>90</td>
    </tr>

</table>

⚡ Quick Revision

  • <form> creates a form.
  • <input> collects user information.
  • <button> creates a button.
  • <table> creates a table.
  • <tr> represents a table row.
  • <th> represents a table heading.
  • <td> represents table data.

04. CSS Basics 🎨

CSS stands for Cascading Style Sheets. It is used to control the appearance and layout of HTML elements.

CSS Syntax

selector {
    property: value;
}

Example

h1 {
    color: blue;
    font-size: 40px;
}

Here, h1 is the selector, color and font-size are properties, and their values are blue and 40px.

Different Ways to Add CSS

  • Inline CSS
  • Internal CSS
  • External CSS

Class Selector

.card {
    background: white;
    padding: 20px;
}

ID Selector

#heading {
    color: purple;
}

⚡ Quick Revision

  • CSS controls the appearance of HTML.
  • Selectors choose the elements to style.
  • Properties define what should change.
  • External CSS is commonly used for larger websites.

05. Box Model & Positioning 📦

Every HTML element can be treated as a rectangular box. The CSS box model consists of content, padding, border and margin.

The Box Model

.card {

    width: 300px;

    padding: 20px;

    border: 2px solid black;

    margin: 20px;
}

Four Parts

  • Content — actual text or element.
  • Padding — space inside the border.
  • Border — line surrounding the element.
  • Margin — space outside the element.

Position Property

.box {
    position: relative;
}

.box2 {
    position: absolute;
    top: 20px;
    right: 20px;
}

⚡ Quick Revision

  • Padding creates space inside an element.
  • Margin creates space outside an element.
  • Border surrounds the element.
  • Position controls how an element is placed.

06. Flexbox & Grid 🧩

Flexbox and CSS Grid are modern layout systems used to arrange elements on a webpage.

Flexbox

.container {

    display: flex;

    justify-content: center;

    align-items: center;

    gap: 20px;
}

Flexbox is especially useful for arranging elements in a row or column.

CSS Grid

.container {

    display: grid;

    grid-template-columns: repeat(3, 1fr);

    gap: 20px;
}

Grid is useful when creating layouts with rows and columns.

⚡ Quick Revision

  • Flexbox is useful for one-dimensional layouts.
  • Grid is useful for rows and columns.
  • justify-content controls horizontal/main-axis alignment.
  • align-items controls cross-axis alignment.
  • gap creates space between items.

07. Responsive Design 📱

Responsive design means creating websites that automatically adapt to different screen sizes such as mobile phones, tablets and computers.

Media Queries

@media (max-width: 768px) {

    .container {
        grid-template-columns: 1fr;
    }

    h1 {
        font-size: 35px;
    }

}

The media query above applies the styles when the screen width is 768 pixels or smaller.

Responsive Units

  • %
  • rem
  • em
  • vw
  • vh

⚡ Quick Revision

  • Responsive websites adapt to different screens.
  • Media queries apply styles based on screen conditions.
  • Flexible layouts help websites work on mobile devices.

08. Mini Website Project 🚀

Now combine your HTML and CSS knowledge to create a simple personal webpage.

HTML

<!DOCTYPE html>

<html>

<head>
    <title>My Website</title>
    <link rel="stylesheet" href="style.css">
</head>

<body>

    <header>
        <h1>Welcome to My Website</h1>
        <p>I am learning web development!</p>
    </header>

    <section>
        <h2>My Skills</h2>
        <p>Python | Java | HTML | CSS</p>
    </section>

</body>

</html>

CSS

body {
    font-family: Arial, sans-serif;
    margin: 0;
    text-align: center;
}

header {
    padding: 60px;
    background: #eee8ff;
}

h1 {
    color: #5b4bdb;
}

section {
    padding: 40px;
}

Try changing the colors, fonts, spacing and layout. This is how you move from simply learning HTML and CSS to actually building websites. 💻

⚡ Quick Revision

  • HTML creates the structure.
  • CSS controls the design.
  • Flexbox and Grid create layouts.
  • Media queries make websites responsive.
  • Practice by building small projects.

🚀 HTML & CSS Quick Revision

  • HTML → structure of a webpage.
  • CSS → styling and design.
  • HTML uses tags and elements.
  • CSS uses selectors, properties and values.
  • Padding → inside space.
  • Margin → outside space.
  • Flexbox → flexible layout.
  • Grid → rows and columns.
  • Media queries → responsive design.
  • HTML + CSS → foundation of web development.
