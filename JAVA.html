JAVA NOTES

Learn Java Step by Step 📚

These notes cover the important Java concepts you need to build a strong programming foundation.

01. Java Basics ☕

Java is a high-level, object-oriented programming language used to build applications for computers, mobile devices, web applications and many other platforms.

Java follows the idea of "Write Once, Run Anywhere". Java programs are compiled into bytecode that can run on different systems using the Java Virtual Machine (JVM).

Important Features of Java

  • Object-oriented
  • Platform independent
  • Simple and easy to learn
  • Secure
  • Robust
  • Supports multithreading

JDK, JRE and JVM

  • JDK: Java Development Kit — used to develop Java programs.
  • JRE: Java Runtime Environment — provides the environment required to run Java programs.
  • JVM: Java Virtual Machine — executes Java bytecode.

First Java Program

public class Main {

    public static void main(String[] args) {

        System.out.println("Hello, World!");

    }
}

System.out.println() is used to display output on the screen.

Comments

// This is a single-line comment

/*
   This is a
   multi-line comment
*/

⚡ Quick Revision

  • Java is an object-oriented programming language.
  • JDK is used to develop Java programs.
  • JRE provides the runtime environment.
  • JVM executes Java bytecode.
  • System.out.println() displays output.

02. Variables & Data Types 📦

A variable is a named memory location used to store data. Every variable in Java has a data type.

Creating a Variable

int age = 20;

double price = 99.50;

String name = "Alex";

boolean isStudent = true;

Common Data Types

  • int — whole numbers
  • double — decimal numbers
  • char — a single character
  • boolean — true or false
  • String — sequence of characters

Example

int marks = 85;
double height = 5.4;
char grade = 'A';
boolean passed = true;
String name = "Rahul";

Type Casting

Type casting means converting one data type into another. 

double number = 10.5;

int value = (int) number;

System.out.println(value);

⚡ Quick Revision

  • A variable stores data.
  • Every variable has a data type.
  • int stores whole numbers.
  • double stores decimal numbers.
  • boolean stores true or false.
  • String stores text.

03. Operators ➕

Operators are symbols used to perform operations on values and variables.

Arithmetic Operators

int a = 10;
int b = 3;

System.out.println(a + b);
System.out.println(a - b);
System.out.println(a * b);
System.out.println(a / b);
System.out.println(a % b);

Common arithmetic operators are +, -, *, /, %.

Comparison Operators

a == b
a != b
a > b
a < b
a >= b
a <= b

Logical Operators

&&   AND
||   OR
!    NOT

Assignment Operators

int x = 10;

x += 5;
x -= 2;
x *= 3;
x /= 2;

⚡ Quick Revision

  • Arithmetic operators perform calculations.
  • Comparison operators compare values.
  • Logical operators combine conditions.
  • Assignment operators assign or update values.

04. Conditions & Loops 🔄

Conditions allow a program to make decisions, while loops allow a program to repeat a block of code.

if Statement

int age = 20;

if (age >= 18) {
    System.out.println("You are an adult.");
}

if-else

int marks = 75;

if (marks >= 40) {
    System.out.println("Pass");
} else {
    System.out.println("Fail");
}

for Loop

for (int i = 1; i <= 5; i++) {

    System.out.println(i);

}

while Loop

int i = 1;

while (i <= 5) {

    System.out.println(i);

    i++;
}

⚡ Quick Revision

  • if is used for decision making.
  • else runs when the condition is false.
  • for loop is useful when repetitions are known.
  • while loop repeats while a condition is true.

05. Methods 🔧

A method is a block of code designed to perform a particular task. Methods help us reuse code.

Creating a Method

static void greet() {

    System.out.println("Hello!");

}

Calling a Method

greet();

Method with Parameters

static void greet(String name) {

    System.out.println("Hello " + name);

}

Here, name is a parameter passed to the method.

Method with Return Value

static int add(int a, int b) {

    return a + b;

}

⚡ Quick Revision

  • Methods make code reusable.
  • Methods can accept parameters.
  • Methods can return a value.
  • Method overloading allows multiple methods with the same name but different parameters.

06. Arrays 📊

An array is used to store multiple values of the same data type in a single variable.

Creating an Array

int[] numbers = {10, 20, 30, 40, 50};

Accessing Elements

System.out.println(numbers[0]);
System.out.println(numbers[2]);

Array indexing starts from 0.

Loop Through an Array

for (int i = 0; i < numbers.length; i++) {

    System.out.println(numbers[i]);

}

Enhanced for Loop

for (int number : numbers) {

    System.out.println(number);

}

⚡ Quick Revision

  • Arrays store multiple values.
  • Array elements have indexes.
  • The first index is 0.
  • length gives the number of elements.

07. Object-Oriented Programming 🧩

Java is an object-oriented programming language. OOP organizes programs using classes and objects.

Class

A class is a blueprint used to create objects. 

class Student {

    String name;
    int age;

}

Object

An object is an instance of a class. 

Student student1 = new Student();

student1.name = "Anu";
student1.age = 20;

Inheritance

Inheritance allows one class to acquire properties and methods from another class. 

class Animal {

    void eat() {
        System.out.println("Eating");
    }
}

class Dog extends Animal {

    void bark() {
        System.out.println("Barking");
    }
}

Polymorphism

Polymorphism means "many forms". It allows the same method name to behave differently in different situations.

⚡ Quick Revision

  • Class is a blueprint.
  • Object is an instance of a class.
  • Inheritance allows code reuse between classes.
  • Polymorphism means many forms.
  • Encapsulation protects and controls access to data.

08. Exception Handling 🛡️

Exception handling allows Java programs to handle unexpected situations during execution.

try and catch

try {

    int result = 10 / 0;

} catch (ArithmeticException e) {

    System.out.println("Cannot divide by zero.");

}

finally

try {

    System.out.println("Try block");

} catch (Exception e) {

    System.out.println("Exception occurred");

} finally {

    System.out.println("This always executes");

}

throw

The throw keyword can be used to explicitly create an exception. 

throw new ArithmeticException("Invalid operation");

⚡ Quick Revision

  • Exceptions are unexpected events during program execution.
  • try contains code that may cause an exception.
  • catch handles the exception.
  • finally executes after try/catch.
  • throw is used to explicitly throw an exception.

  • Conditions make decisions.
  • Loops repeat code.

  • Arrays store multiple values.
  • OOP uses classes and objects.
  • Exception handling manages runtime problems.
