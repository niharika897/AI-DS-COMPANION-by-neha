01. AI & ML Basics 🤖

What is Artificial Intelligence?

Artificial Intelligence (AI) is a field of computer science that focuses on creating systems capable of performing tasks that normally require human intelligence.

These tasks can include understanding language, recognizing images, making decisions, solving problems and learning from information.

Examples of AI

  • Voice assistants
  • Chatbots
  • Face recognition
  • Recommendation systems
  • Self-driving technology
  • AI-powered medical systems

What is Machine Learning?

Machine Learning (ML) is a branch of AI where computers learn patterns from data instead of being explicitly programmed for every possible situation.

For example, instead of manually programming a computer to recognize every type of spam email, we can provide examples of spam and non-spam emails. A machine learning algorithm can learn patterns from those examples.

AI vs Machine Learning

🤖 AI → Broad field
🧠 ML → Part of AI
📚 AI can use many techniques
📊 ML learns from data

What is Deep Learning?

Deep Learning is a subfield of machine learning that uses neural networks with multiple layers to learn complex patterns from large amounts of data.

Deep learning is commonly used in image recognition, speech recognition, natural language processing and many modern AI applications.

What is Generative AI?

Generative AI refers to AI systems that can generate new content such as text, images, audio, video or computer code based on learned patterns.

🎯 Important Points

  • AI is the broader field of intelligent systems.
  • Machine Learning is a branch of AI.
  • ML learns patterns from data.
  • Deep Learning uses multi-layer neural networks.
  • Generative AI creates new content.

02. Types of Machine Learning 🧠

Machine Learning can be broadly divided into Supervised Learning, Unsupervised Learning and Reinforcement Learning.

1. Supervised Learning

In supervised learning, the model is trained using labelled data. This means that the input data already has a known correct output.

The model learns the relationship between the input and output and then uses that relationship to make predictions for new data.

Example:

Input → House size, location, rooms

Output → House price

Types of Supervised Learning

  • Regression: predicts numerical values.
  • Classification: predicts categories or classes.

2. Unsupervised Learning

In unsupervised learning, the data does not contain labelled answers. The algorithm tries to discover hidden patterns or structures in the data.

For example, a company may use customer information to automatically group customers with similar characteristics.

Example: 
Customer Data
      ↓
Machine Learning Algorithm
      ↓
Customer Groups

3. Reinforcement Learning

Reinforcement learning is a type of machine learning where an agent learns by interacting with an environment.

The agent receives rewards for desirable actions and penalties for undesirable actions. 

Agent
  ↓
Action
  ↓
Environment
  ↓
Reward / Penalty
  ↓
Learning

Simple Comparison

📚 Supervised → Labelled data
🔍 Unsupervised → Unlabelled data
🎮 Reinforcement → Rewards & penalties
📈 Regression → Numbers

🎯 Remember

  • Supervised = learn from labelled examples.
  • Unsupervised = find patterns in data.
  • Reinforcement = learn through interaction.
  • Regression = numerical prediction.
  • Classification = category prediction.

03. Data & Data Preprocessing 📊

Data is the foundation of machine learning. Before training a model, raw data usually needs to be cleaned and transformed into a suitable format.

What are Features?

Features are the input variables used by a machine learning model to make predictions.

For example, when predicting a house price, the number of bedrooms, location and house size can be features.

What is a Label?

A label is the target value that we want the model to predict in supervised learning.

Data Cleaning

Real-world datasets can contain missing values, duplicate records, incorrect values and unnecessary information. Data cleaning helps improve the quality of the dataset.

  • Handle missing values
  • Remove duplicate records
  • Correct invalid values
  • Remove unnecessary columns
  • Handle inconsistent data

Encoding Categorical Data

Machine learning algorithms generally work with numerical values. Therefore, categorical values may need to be converted into numerical representations.

Example:

Gender

Male   → 0
Female → 1

Feature Scaling

Feature scaling is used when features have very different numerical ranges.

Common techniques include Normalization and Standardization.

Training and Testing Data

A dataset is commonly divided into training data and testing data.

  • Training data: used to train the model.
  • Testing data: used to evaluate the model on unseen data.

Basic Workflow

Raw Data
   ↓
Data Cleaning
   ↓
Data Transformation
   ↓
Feature Selection
   ↓
Train / Test Split
   ↓
Machine Learning Model

🎯 Important Terms

  • Feature = input variable
  • Label = target/output
  • Training data = used for learning
  • Testing data = used for evaluation
  • Preprocessing = preparing raw data

04. Regression 📈

Regression is a supervised machine learning technique used to predict continuous numerical values.

Example

Suppose we want to predict the price of a house. The model can learn from previous houses and their prices. 

House Size + Location + Rooms
              ↓
        Regression Model
              ↓
        Predicted Price

Linear Regression

Linear Regression is one of the simplest regression algorithms.

It attempts to model the relationship between input variables and a numerical output using a linear relationship. 

y = mx + c

Where:

  • y = predicted value
  • x = input
  • m = slope
  • c = intercept

Where is Regression Used?

  • House price prediction
  • Sales forecasting
  • Temperature prediction
  • Demand forecasting
  • Revenue prediction

Simple Python Example

from sklearn.linear_model import LinearRegression

model = LinearRegression()

model.fit(X_train, y_train)

prediction = model.predict(X_test)

print(prediction)

🎯 Remember

  • Regression is supervised learning.
  • It predicts numerical values.
  • Linear Regression is a basic regression algorithm.
  • The target variable is continuous.

05. Classification 🏷️

Classification is a supervised machine learning technique used to assign data to predefined categories or classes.

Examples

  • Spam / Not Spam
  • Pass / Fail
  • Positive / Negative
  • Fraud / Not Fraud
  • Disease / No Disease

Binary Classification

Binary classification has two possible classes. 

Email
  ↓
Classification Model
  ↓
Spam OR Not Spam

Multiclass Classification

Multiclass classification contains more than two possible classes.

For example, an image classification model might classify an image as a cat, dog, horse or bird.

Common Classification Algorithms

  • Logistic Regression
  • Decision Tree
  • K-Nearest Neighbors (KNN)
  • Support Vector Machine (SVM)
  • Naive Bayes

Simple Python Example

from sklearn.tree import DecisionTreeClassifier

model = DecisionTreeClassifier()

model.fit(X_train, y_train)

prediction = model.predict(X_test)

print(prediction)

🎯 Remember

  • Classification predicts categories.
  • Binary classification has two classes.
  • Multiclass classification has multiple classes.
  • Classification is supervised learning.

06. Model Evaluation 📏

After training a machine learning model, we need to evaluate how well it performs on unseen data.

Why Do We Evaluate Models?

A model may perform very well on its training data but perform poorly on new data. Evaluation helps us understand whether the model generalizes well.

Accuracy

Accuracy represents the proportion of predictions that were correct. 

Accuracy =
Correct Predictions
-------------------
Total Predictions

Confusion Matrix

A confusion matrix is commonly used to understand the performance of a classification model.

  • True Positive (TP): correctly predicted positive.
  • True Negative (TN): correctly predicted negative.
  • False Positive (FP): predicted positive when the actual class was negative.
  • False Negative (FN): predicted negative when the actual class was positive.

Precision

Precision tells us, among the cases predicted as positive, how many were actually positive. 

Precision = TP / (TP + FP)

Recall

Recall tells us, among the actual positive cases, how many were correctly identified. 

Recall = TP / (TP + FN)

F1 Score

The F1 score combines precision and recall into a single metric using their harmonic mean. 

F1 Score =
2 × Precision × Recall
----------------------
Precision + Recall

Overfitting

Overfitting occurs when a model learns the training data too closely and performs poorly on new, unseen data.

Underfitting

Underfitting occurs when a model is too simple to capture the important patterns in the data.

🎯 Important Points

  • Accuracy measures overall correctness.
  • Precision focuses on predicted positives.
  • Recall focuses on actual positives.
  • F1 combines precision and recall.
  • Overfitting means poor generalization.
  • Underfitting means the model is too simple.

07. Neural Networks & Deep Learning 🧠

A Neural Network is a machine learning model inspired by the way biological neural networks process information.

Basic Structure

A neural network generally contains an input layer, one or more hidden layers and an output layer. 

Input Layer
     ↓
Hidden Layer
     ↓
Hidden Layer
     ↓
Output Layer

Neuron

A neuron receives input values, applies weights and a bias, and then passes the result through an activation function.

Weights

Weights determine how important different inputs are to the model's prediction. During training, the model adjusts these values to reduce prediction errors.

Bias

A bias is an additional parameter that helps the model adjust the output of a neuron.

Activation Functions

Activation functions introduce non-linearity into neural networks, allowing them to learn complex relationships.

  • ReLU
  • Sigmoid
  • Tanh
  • Softmax

Forward Propagation

During forward propagation, input data moves through the network from the input layer toward the output layer to produce a prediction.

Backpropagation

Backpropagation is a training method used to calculate how much each parameter contributed to the error and update the network parameters accordingly.

What is Deep Learning?

Deep Learning uses neural networks with multiple layers to learn increasingly complex representations from data.

Applications

  • Image recognition
  • Speech recognition
  • Natural language processing
  • Computer vision
  • Recommendation systems
  • Generative AI

🎯 Remember

  • Neural networks contain connected neurons.
  • Weights and biases are learned parameters.
  • Activation functions add non-linearity.
  • Forward propagation produces predictions.
  • Backpropagation helps train the network.
  • Deep learning uses multiple neural network layers.

08. AI Project Workflow 🚀

Building an AI or Machine Learning project involves several stages. A good project begins with a clear problem and ends with evaluation and deployment.

Step 1 — Define the Problem

Clearly identify what problem you are trying to solve and what the model should predict or accomplish.

Step 2 — Collect Data

Collect relevant and useful data from appropriate sources.

Step 3 — Explore the Data

Examine the dataset to understand its structure, values, patterns and possible problems.

Step 4 — Preprocess the Data

Clean the dataset, handle missing values, transform features and prepare the data for training.

Step 5 — Split the Dataset

Divide the available data into training and testing portions. Validation data may also be used during model development.

Step 6 — Select a Model

Choose an appropriate machine learning algorithm based on the type of problem and data.

Step 7 — Train the Model

The model learns patterns from the training data.

Step 8 — Evaluate the Model

Use suitable evaluation metrics to understand how well the model performs on unseen data.

Step 9 — Improve the Model

Improve performance through better preprocessing, feature engineering, model selection or parameter tuning.

Step 10 — Deploy the Model

A trained model can be integrated into an application or service so that users can interact with it.
