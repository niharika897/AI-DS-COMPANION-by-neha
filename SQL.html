SQL NOTES

Learn SQL Step by Step 📚

These notes cover the important SQL concepts you need to work with databases and write useful queries.

01. SQL Basics 🗄️

SQL stands for Structured Query Language. It is used to communicate with databases and perform operations on stored data.

A database contains tables, and tables contain rows and columns.

  • Database → stores organized data
  • Table → stores related information
  • Row → represents one record
  • Column → represents a type of information
CREATE DATABASE college;

CREATE TABLE students (
    id INT,
    name VARCHAR(50),
    age INT
);

Quick Revision ⚡

  • SQL is used to work with databases.
  • Tables contain rows and columns.
  • SQL commands perform different database operations.

02. SELECT & WHERE 🔍

The SELECT statement is used to retrieve data from a table.

The WHERE clause is used to filter records based on a condition. 

SELECT * FROM students;

SELECT name, age
FROM students
WHERE age > 18;
  • SELECT * → selects all columns
  • SELECT name → selects a specific column
  • WHERE → filters records

Quick Revision ⚡

  • SELECT retrieves data.
  • WHERE filters data.
  • Conditions decide which records are returned.

03. Sorting & Filtering 📊

SQL provides different commands for organizing and filtering query results. 

SELECT *
FROM students
ORDER BY age ASC;

SELECT *
FROM students
WHERE name LIKE 'A%';
  • ORDER BY → sorts results
  • ASC → ascending order
  • DESC → descending order
  • LIKE → searches for patterns
  • AND / OR → combines conditions

Quick Revision ⚡

  • ORDER BY sorts data.
  • ASC sorts from low to high.
  • DESC sorts from high to low.
  • LIKE is useful for pattern matching.

04. INSERT, UPDATE & DELETE ✏️

These commands are used to add, modify and remove records from a table. 

INSERT INTO students
VALUES (1, 'Anu', 20);

UPDATE students
SET age = 21
WHERE id = 1;

DELETE FROM students
WHERE id = 1;
  • INSERT → adds new records
  • UPDATE → changes existing records
  • DELETE → removes records

Quick Revision ⚡

  • INSERT adds data.
  • UPDATE modifies data.
  • DELETE removes data.
  • Always use WHERE carefully with UPDATE and DELETE.

05. Functions & Aggregation 🧮

Aggregate functions perform calculations on multiple rows and return a single result. 

SELECT COUNT(*) FROM students;

SELECT AVG(age) FROM students;

SELECT MAX(age) FROM students;

SELECT MIN(age) FROM students;

SELECT SUM(age) FROM students;
  • COUNT() → counts records
  • SUM() → calculates total
  • AVG() → calculates average
  • MAX() → finds maximum value
  • MIN() → finds minimum value

Quick Revision ⚡

  • Aggregate functions work on multiple rows.
  • COUNT counts records.
  • AVG calculates the average.
  • MAX and MIN find extreme values.

06. GROUP BY & HAVING 📦

GROUP BY groups rows that have the same values. HAVING filters grouped results. 

SELECT age, COUNT(*)
FROM students
GROUP BY age;

SELECT age, COUNT(*)
FROM students
GROUP BY age
HAVING COUNT(*) > 1;
  • GROUP BY → creates groups
  • HAVING → filters groups
  • Aggregate functions are commonly used with GROUP BY

Quick Revision ⚡

  • GROUP BY groups similar values.
  • HAVING filters groups.
  • WHERE filters rows before grouping.

07. SQL Joins 🔗

Joins are used to combine data from two or more related tables. 

SELECT students.name, courses.course_name
FROM students
INNER JOIN courses
ON students.course_id = courses.id;
  • INNER JOIN → returns matching records
  • LEFT JOIN → keeps all records from the left table
  • RIGHT JOIN → keeps all records from the right table

Quick Revision ⚡

  • Joins connect related tables.
  • INNER JOIN returns matching records.
  • LEFT JOIN keeps all rows from the left table.
  • RIGHT JOIN keeps all rows from the right table.

08. Keys & Database Design 🔑

Keys help identify records and create relationships between tables.

  • Primary Key → uniquely identifies a record.
  • Foreign Key → connects one table to another.
  • Relationships → describe how tables are connected.
CREATE TABLE courses (
    id INT PRIMARY KEY,
    course_name VARCHAR(50)
);

CREATE TABLE students (
    id INT PRIMARY KEY,
    name VARCHAR(50),
    course_id INT,
    FOREIGN KEY (course_id)
        REFERENCES courses(id)
);

Quick Revision ⚡

  • Primary keys uniquely identify records.
  • Foreign keys connect related tables.
  • Good database design keeps data organized.

SQL Quick Revision 🚀

  • SQL is used to work with databases.
  • SELECT retrieves data.
  • WHERE filters records.
  • ORDER BY sorts results.
  • INSERT, UPDATE and DELETE modify data.
  • Aggregate functions perform calculations.
  • GROUP BY creates groups.
  • Joins combine related tables.
  • Primary and foreign keys create database relationships.
