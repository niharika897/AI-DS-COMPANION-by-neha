01. DSA Basics 🧠

What is DSA?

DSA stands for Data Structures and Algorithms. It is one of the most important foundations of programming and problem solving.

A data structure is a way of organizing and storing data so that it can be accessed and modified efficiently. An algorithm is a step-by-step procedure used to solve a particular problem.

What is a Data Structure?

A data structure organizes data in a particular way so that operations such as searching, inserting, deleting and updating can be performed efficiently.

Examples include:

  • Arrays
  • Linked Lists
  • Stacks
  • Queues
  • Trees
  • Graphs
  • Hash Tables

What is an Algorithm?

An algorithm is a finite sequence of clear steps used to solve a problem or perform a computation. 

Problem
   ↓
Understand the problem
   ↓
Design an algorithm
   ↓
Write the program
   ↓
Test the solution

Time Complexity ⏱️

Time complexity describes how the running time of an algorithm changes as the input size increases.

Common complexities include:

  • O(1) → Constant time
  • O(log n) → Logarithmic time
  • O(n) → Linear time
  • O(n log n) → Common efficient sorting complexity
  • O(n²) → Quadratic time

Space Complexity 💾

Space complexity describes how much additional memory an algorithm needs as the input size increases.

🎯 Quick Revision

  • Data Structure → organizes data.
  • Algorithm → solves a problem step by step.
  • Time Complexity → measures growth of running time.
  • Space Complexity → measures additional memory usage.

02. Arrays 📦

What is an Array?

An array is a data structure used to store multiple values under one variable name. The elements can be accessed using an index. 

int numbers[] = {10, 20, 30, 40, 50};

Array indexing generally starts from 0. 

Index:    0    1    2    3    4
Value:   10   20   30   40   50

Common Array Operations

  • Traversal
  • Searching
  • Insertion
  • Deletion
  • Updating

Array Traversal

for(int i = 0; i < n; i++) {
    System.out.println(numbers[i]);
}

Advantages

  • Fast access using an index.
  • Simple to understand and use.
  • Useful for storing collections of similar data.

Disadvantages

  • Insertion and deletion can require shifting elements.
  • Fixed-size arrays have limited capacity.

🎯 Quick Revision

  • Array stores multiple elements.
  • Indexing generally starts at 0.
  • Access by index is efficient.
  • Insertion/deletion can be expensive depending on position.

03. Strings 🔤

What is a String?

A string is a sequence of characters. Strings are commonly used to store names, sentences, messages and other text. 

String name = "Student";

Common String Operations

  • Finding the length
  • Accessing characters
  • Comparing strings
  • Concatenating strings
  • Searching for characters or substrings
  • Changing case

Example

String text = "Hello";

System.out.println(text.length());
System.out.println(text.charAt(0));

Common String Problems

  • Reverse a string
  • Check whether a string is a palindrome
  • Count characters
  • Find duplicate characters
  • Check whether two strings are anagrams

Palindrome

A palindrome is a word or sequence that reads the same forward and backward. 

madam → palindrome
hello → not a palindrome

🎯 Quick Revision

  • String → sequence of characters.
  • Strings are frequently used in programming problems.
  • Common problems include reversal and palindrome checking.

04. Linked Lists 🔗

What is a Linked List?

A linked list is a linear data structure made up of nodes. Each node contains data and a reference to another node. 

[10 | next] → [20 | next] → [30 | null]

Node

A node generally contains:

  • Data
  • Reference to the next node

Types of Linked Lists

  • Singly Linked List
  • Doubly Linked List
  • Circular Linked List

Advantages

  • Dynamic size.
  • Insertion and deletion can be efficient when the position/reference is known.
  • Does not require contiguous storage like a traditional array.

Disadvantages

  • No direct random access by index.
  • Extra memory is needed for references.

Basic Structure

class Node {

    int data;
    Node next;

}

🎯 Quick Revision

  • Linked List consists of nodes.
  • Each node stores data and a reference.
  • Common types are singly, doubly and circular.
  • Linked lists are useful when dynamic insertion/deletion is needed.

05. Stacks & Queues 📚

Stack

A stack is a linear data structure that follows the LIFO principle.

LIFO means Last In, First Out. 

Push 30
Push 20
Push 10

Top
 ↓
[10]
[20]
[30]

Common Stack Operations

  • Push → add an element.
  • Pop → remove the top element.
  • Peek → view the top element.

Applications of Stack

  • Undo operations
  • Browser history
  • Function call management
  • Expression evaluation
  • Backtracking

Queue

A queue follows the FIFO principle.

FIFO means First In, First Out. 

Front
  ↓
[10] [20] [30]
             ↑
           Rear

Common Queue Operations

  • Enqueue → add an element.
  • Dequeue → remove an element.
  • Front/Peek → view the front element.

Stack vs Queue

📚 Stack → LIFO
🚶 Queue → FIFO

🎯 Remember

  • Stack → Last In, First Out.
  • Queue → First In, First Out.
  • Stack uses push and pop.
  • Queue uses enqueue and dequeue.

06. Trees 🌳

What is a Tree?

A tree is a non-linear data structure made up of nodes connected by edges. 

        10
       /  \
      5    20
     / \
    2   7

Important Terms

  • Root: topmost node.
  • Parent: node connected to child nodes.
  • Child: node below another node.
  • Leaf: node with no children.
  • Edge: connection between nodes.
  • Height: length of the longest path from a node to a leaf.

Binary Tree

A binary tree is a tree where each node can have at most two children.

Binary Search Tree

In a Binary Search Tree, values smaller than a node are generally placed in its left subtree and larger values in its right subtree.

Tree Traversals

  • Preorder: Root → Left → Right
  • Inorder: Left → Root → Right
  • Postorder: Left → Right → Root
  • Level Order: Visit level by level

🎯 Quick Revision

  • Tree is a non-linear data structure.
  • Root is the topmost node.
  • Binary tree has at most two children per node.
  • BST organizes values according to ordering rules.
  • Tree traversal is used to visit nodes.

07. Searching & Sorting 🔍

Searching

Searching means finding a particular element in a collection of data.

Linear Search

Linear search checks elements one by one until the required element is found or the collection ends. 

for(int i = 0; i < n; i++) {

    if(arr[i] == target) {
        System.out.println("Found");
    }

}

Average/worst-case time complexity: O(n).

Binary Search

Binary search works on a sorted collection. It repeatedly divides the search range into two parts. 

Sorted Array
     ↓
Check Middle
     ↓
Target smaller?
  ↙        ↘
Left      Right
     ↓
Repeat

Time complexity: O(log n).

Sorting

Sorting means arranging data in a particular order, such as ascending or descending order.

Common Sorting Algorithms

  • Bubble Sort
  • Selection Sort
  • Insertion Sort
  • Merge Sort
  • Quick Sort

Bubble Sort

Bubble Sort repeatedly compares adjacent elements and swaps them when they are in the wrong order. 

[5] [2] [4] [1]

Compare → Swap
Compare → Swap
Compare → Swap

Repeat until sorted.

Basic Bubble Sort has a worst-case time complexity of O(n²).

🎯 Remember

  • Linear Search → O(n).
  • Binary Search → O(log n), requires sorted data.
  • Sorting arranges data in an order.
  • Bubble Sort → O(n²) worst case.
  • Merge Sort and Quick Sort are important advanced sorting algorithms.

08. Problem Solving 🧩

Why is Problem Solving Important?

Learning DSA is not only about memorizing algorithms. The main goal is to learn how to analyze a problem, design a solution and implement it efficiently.

A Simple Problem-Solving Process

Understand the Problem
        ↓
Identify Input & Output
        ↓
Find Constraints
        ↓
Think of a Simple Solution
        ↓
Improve the Approach
        ↓
Choose the Data Structure
        ↓
Write the Algorithm
        ↓
Code
        ↓
Test
        ↓
Analyze Complexity

Understand the Constraints

Constraints tell you how large the input can be. They can help determine which algorithm is practical.

Brute Force

A brute-force solution tries a straightforward approach, often checking many possible possibilities. It can be useful as a starting point before looking for a more efficient solution.

Optimization

After finding a basic solution, try to reduce unnecessary work and improve time or memory usage.

Common Problem-Solving Techniques

  • Two Pointers
  • Sliding Window
  • Binary Search
  • Recursion
  • Hashing
  • Greedy Approach
  • Divide and Conquer
  • Dynamic Programming

Practice Strategy

  • Start with easy problems.
  • Understand the problem before coding.
  • Write down your approach.
  • Test with small examples.
  • Analyze time and space complexity.
  • Learn from mistakes.
  • Gradually solve harder problems.

🎯 Golden Rule

Don't focus only on memorizing code. Focus on understanding why an algorithm works and when to use it.
